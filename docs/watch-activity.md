# Watch Activity

Activity shows today's measured steps inside a static orange goal ring. The ring
fills to 100%; the percentage can exceed the goal (values above 999% show >999%).
The existing minus/plus controls adjust the persisted daily goal in 1,000-step
increments, from 1,000 to 30,000. Save failures retain the previous goal.

The seven-day chart runs oldest to newest, with Today on the right in orange.
Tap a day to see its exact step count above the chart. The outlined column marks
the selected day. A dashed horizontal line marks the current daily goal, not
historical goals. Heights scale to the larger of the goal or highest daily count.
Zero counts have a subtle baseline; unavailable history shows dashes and cannot
be selected. Today always uses the live counter, avoiding a stale history snapshot.

No distance, calories, new sensors, storage or phone protocol changes are added.
The existing midnight rollover, step detection and goal persistence are unchanged.

Manual checks: inspect ring/text spacing; tap all days; try +/- and confirm goal
after reboot; walk and check live updates; sleep/wake; Back and right swipe.
